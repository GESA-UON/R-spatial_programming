# R Spatial Programming

Welcome to the **R Spatial Programming** repository, maintained by [GESA-UON]. This repository contains introductory materials, scripts, and tutorials designed to teach the fundamentals of R programming with a specific focus on geospatial data analysis.

## 📖 Overview

This repository is built for beginners and intermediate users who want to transition into spatial analytics using R. It bridges the gap between basic R syntax and advanced geospatial operations. 

**Topics Covered:**
*   **R Fundamentals:** Variables, data structures (vectors, data frames), control flow, and functions.
*   **Spatial Data Handling:** Importing, manipulating, and exporting vector (shapefiles, GeoJSON) and raster (GeoTIFF) data.
*   **Spatial Operations:** Coordinate Reference Systems (CRS), spatial joins, buffering, and intersections.
*   **Geospatial Visualization:** Creating static and interactive maps using R.

## 🛠️ Prerequisites

Before you begin, ensure you have the following installed on your machine:

1.  **[R](https://cran.r-project.org/):** The core programming language.
2.  **[RStudio](https://posit.co/download/rstudio-desktop/):** The recommended Integrated Development Environment (IDE) for R.

*Note: Basic familiarity with programming concepts is helpful but not strictly required for the introductory modules.*
